# 日常涨跌预测与复盘

完整市场分析在获取本轮行情后执行本步骤。只对本轮覆盖、有合格数据且能代表所问市场的少数锚点判断方向，例如币圈用 BTC、美股用实际宽基指数或 ETF、A 股用实际宽基指数。组合分析可以只预测适用市场；不能用重仓个股替代宽基。使用已有合法行情范围，缺少指数时披露缺口，不为预测扩大批量范围或再次刷新。账户盘点和账户动作不执行此步骤。

1. **证据与推断**：标注方向判断所用事实、计算、机构观点或推断。重要证据注明数据时间、口径和来源。同一消息的转载不算独立证据。旧数据只做背景，关键数据不足写“方向待确认”并说明缺项。
2. **预测周期**：每次完整分析先给未来一个月和一个季度的方向，再补充短期和波段。月度以同一日历时刻一个月后的时间为目标，在 28–35 天内选可复核终点，关注月线结构、周线确认与持续资金流。季度以三个月后的时间为目标，在 84–98 天内选终点，关注季线结构、月线趋势、流动性与市场广度。注明未收完的月线、季线，不把盘中变化写成收线确认。短期选未来 1–3 天，关注价格结构、成交与杠杆。波段选未来 1–4 周内的终点，关注周线结构、持续资金流与上涨广度。A 股和美股终点必须是实际交易时点，遇休市选窗口内临近的有效交易日，明确时区。无合格终点或证据不足时，明确该周期方向待确认。起点和终点采用同一标的、市场、币种、价格类型、复权口径。股价发生拆股等口径变化时暂缓评分。
3. **主次情景**：主方向与备选方向从上涨、下跌、震荡中选。事先固定终点、起点价格和中性带 ±x%，说明其与周期波动的关系。到期收益严格大于 +x% 判涨，严格小于 -x% 判跌，其余判震荡。区间内曾出现突破不改变到期规则；无校准时用情景排序，不编概率。
4. **反方和改判**：每条写最强的已观察反方证据，以及带标的、阈值、周期和确认方式的改判条件；未找到反方证据时写清核验范围及限制。改判新增记录并引用原预测 ID，原记录继续到期评分。触发价用于复核判断，不直接作为订单。
5. **到期复盘**：分析开头先给月度、季度方向和上次到期结果，再补充短期、波段。只有到期的同口径数据可评分。为检验增量预测能力，在发布时记录简单趋势基准，取相同长度的前一窗口收益，用本条同一中性带定方向。若前窗数据缺失，基准留空。复盘只对有基准的相同样本比较，按市场锚点和周期分组，报告样本数，重叠窗口或修订不可作为独立样本重复计数。单次命中只说明这条预测的结果。没有完整起止区间的高低价，最大反向波动留空。震荡使用最大超出中性带的幅度。未到期、缺到期价格或路径数据分别说明，不从现在价格倒填。

## 币圈与美股联动

每次完整币圈分析，把纳指100或QQQ纳入BTC各周期判断。短期先对齐时间，美股开盘后看现货指数或ETF，盘前和休市时用有时间戳的纳指期货作线索，并注明上次美股收盘日期。波段结合纳指周线和美债收益率，再用BTC的ETF流量、持仓量、资金费率与清算数据验证。月度和季度看纳指周线、月线或季线结构，以及美债收益率和ETF资金流是否持续同向改变。使用本轮已有行情与公开只读补充来源，保持原有批量采集范围。

写明BTC和美股是同步、BTC先行，还是出现背离。BTC先企稳时，用美股开盘后能否企稳和BTC能否守住先行低点验证；美股反弹而BTC持续走弱时，核查币圈自身资金流或事件，并降低对BTC反转的信心。缺同期证据时写明联动未确认。每条BTC方向预测说明美股证据如何影响主情景，以及什么变化会使判断失效。

## 共用记录

使用 `scripts/market-forecast.ps1`，默认记录在 `state/forecasts/market.jsonl`。该记录只用于预测和复盘。首次使用没有历史记录时写“暂无到期预测”。

| 调用 | 输入 |
|---|---|
| `-Action list [-Symbol <标的>] [-Limit 8]` | 查看最近记录和待复盘的到期预测。按本轮标的查询，使用现有合格的历史数据；缺失则留待后续。 |
| `-Action record -DataJson <JSON>` | 发布前保存。字段包括 `id`、`symbol`（含市场）、`basis`（价格口径）、`source`（快照路径或可追溯来源）、`observedAt`、`expiresAt`（带时区 ISO 时间）、`startPrice`、`bandPct`、`horizon`（short/swing/monthly/quarterly）、`direction`、`alternative`（up/down/range）、`evidence`、`counterEvidence`、`invalidation`。可选 `baselineDirection`、`baselineEvidence`、`revisionOf`。 |
| `-Action review -DataJson <JSON>` | 字段：原 `id`、`symbol`、`basis`、`source`、`observedAt`（原定终点的实际观测时间）、`endPrice`。有完整路径时同时提供 `windowHigh`、`windowLow`、`pathSource`。输出实际方向、命中结果、基准结果与最大反向波动。 |

历史资料只可用于隔离验证。真实记录以发布当时为准，历史重演不能写入默认账本或计入实时预测成绩。
