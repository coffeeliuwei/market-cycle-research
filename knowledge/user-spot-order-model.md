# 现货挂单与回放
分析一笔订单时记录交易场所、实际品种、币种、方向、限价、数量、冻结金额和有效状态。按标的汇总不同场所的敞口，不同保证金池分别核算。
1. 观察建单地点与最终承担风险的成交地点，区分报价、触发与成交。重复撤改形成同一决策组。
2. 先估算各档依次成交后的现金占用和敞口。分别模拟继续下跌、浅回撤未成交、急跌反弹；对标的恶化保留失效条件。
3. 报告备选动作与维持原单的差异，使用原生交易单位。建议用 order.proposed 记录；收到明确执行结果后再转为账户事实。
4. 使用 replay-binance-spot-history.ps1 回放导出。缺少归因证据记 unknown。已匹配成本的收益、未平仓成本和未能匹配的卖出分别计算；限制结论至导出所覆盖的账户和时间。
